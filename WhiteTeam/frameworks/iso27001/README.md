# ISO 27001:2022 Framework Reference

## Overview

ISO/IEC 27001:2022 is the international standard for Information Security Management Systems (ISMS).

## Structure

### ISMS Requirements (Clauses 4-10)
- **Clause 4**: Context of the organization
- **Clause 5**: Leadership
- **Clause 6**: Planning
- **Clause 7**: Support
- **Clause 8**: Operation
- **Clause 9**: Performance evaluation
- **Clause 10**: Improvement

### Annex A Controls (93 controls)

| Category | Name | Controls |
|----------|------|----------|
| A.5 | Organizational Controls | 37 |
| A.6 | People Controls | 8 |
| A.7 | Physical Controls | 14 |
| A.8 | Technological Controls | 34 |

## Key Documents

- Statement of Applicability (SoA)
- Risk Assessment Methodology
- Risk Treatment Plan
- Information Security Policy
- Internal Audit Program
- Management Review Records

## Certification Requirements

1. Documented ISMS
2. Risk assessment process
3. Risk treatment implementation
4. Internal audits
5. Management review
6. Continual improvement
