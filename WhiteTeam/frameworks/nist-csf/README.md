# NIST Cybersecurity Framework 2.0 Reference

## Overview

The NIST Cybersecurity Framework (CSF) provides a policy framework of computer security guidance for organizations to assess and improve their ability to prevent, detect, and respond to cyber attacks.

## Implementation Tiers

| Tier | Name | Description |
|------|------|-------------|
| 1 | Partial | Ad hoc, reactive |
| 2 | Risk Informed | Risk aware but not org-wide |
| 3 | Repeatable | Formal, org-wide policies |
| 4 | Adaptive | Continuous improvement |

## Profiles

### Current Profile
- Documents current cybersecurity posture
- Identifies existing practices
- Maps to framework categories

### Target Profile
- Defines desired cybersecurity state
- Aligns with business objectives
- Prioritizes improvements

## Key Changes in 2.0

1. **GOVERN Function**: New core function for governance
2. **Supply Chain**: Enhanced supply chain risk management
3. **Scope Expansion**: Applies to all organizations, not just critical infrastructure
4. **Profiles**: Enhanced guidance on profile development
5. **Implementation Examples**: More practical guidance

## Implementation Steps

1. **Prioritize and Scope**
   - Identify business objectives
   - Determine scope

2. **Orient**
   - Identify assets and threats
   - Understand current state

3. **Create Current Profile**
   - Document existing practices
   - Map to framework

4. **Conduct Risk Assessment**
   - Identify gaps
   - Prioritize risks

5. **Create Target Profile**
   - Define desired state
   - Set priorities

6. **Determine Gaps**
   - Compare profiles
   - Identify actions

7. **Implement Action Plan**
   - Execute improvements
   - Monitor progress
