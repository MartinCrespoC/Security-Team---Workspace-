# HIPAA Framework Reference

## Overview

The Health Insurance Portability and Accountability Act (HIPAA) establishes national standards for the protection of health information in the United States.

## Key Rules

### Privacy Rule

Establishes standards for the protection of PHI (Protected Health Information).

| Requirement | Description |
|-------------|-------------|
| Use and Disclosure | Limits use and disclosure of PHI |
| Patient Rights | Access, amendment, accounting |
| Notice of Privacy Practices | Inform patients of privacy practices |
| Minimum Necessary | Use minimum PHI necessary |

### Security Rule

Establishes standards for protecting ePHI (electronic PHI).

| Safeguard Type | Description |
|----------------|-------------|
| Administrative | Policies, procedures, workforce |
| Physical | Facility access, workstation security |
| Technical | Access controls, audit controls, encryption |

## Administrative Safeguards (§164.308)

| Standard | Implementation Specifications |
|----------|------------------------------|
| Security Management Process | Risk analysis, risk management, sanction policy, information system activity review |
| Assigned Security Responsibility | Designate security official |
| Workforce Security | Authorization, supervision, clearance, termination |
| Information Access Management | Access authorization, access establishment |
| Security Awareness Training | Security reminders, malware protection, login monitoring, password management |
| Security Incident Procedures | Response and reporting |
| Contingency Plan | Data backup, disaster recovery, emergency mode, testing, applications criticality |
| Evaluation | Periodic evaluation |
| BAA Requirements | Business associate contracts |

## Physical Safeguards (§164.310)

| Standard | Implementation Specifications |
|----------|------------------------------|
| Facility Access Controls | Contingency operations, facility security plan, access control, maintenance records |
| Workstation Use | Appropriate use policies |
| Workstation Security | Physical safeguards |
| Device and Media Controls | Disposal, media re-use, accountability, data backup |

## Technical Safeguards (§164.312)

| Standard | Implementation Specifications |
|----------|------------------------------|
| Access Control | Unique user ID, emergency access, automatic logoff, encryption |
| Audit Controls | Hardware, software, procedural mechanisms |
| Integrity | Mechanism to authenticate ePHI |
| Person/Entity Authentication | Verify identity |
| Transmission Security | Integrity controls, encryption |

## Breach Notification Rule

| Notification | Timeline | Recipient |
|--------------|----------|-----------|
| Individuals | 60 days | Affected individuals |
| HHS | 60 days (>500) / Annual (<500) | Department of HHS |
| Media | 60 days (>500 in state) | Prominent media outlets |

## Required vs Addressable

| Type | Meaning |
|------|---------|
| Required (R) | Must be implemented |
| Addressable (A) | Assess and implement if reasonable, or document alternative |

## Key Documentation

- Risk Analysis
- Risk Management Plan
- Policies and Procedures
- Security Awareness Training Records
- Business Associate Agreements
- Incident Response Plan
- Contingency Plan
- Audit Logs

## Penalties

| Tier | Violation Type | Penalty Range |
|------|---------------|---------------|
| 1 | Unknowing | $100 - $50,000 |
| 2 | Reasonable Cause | $1,000 - $50,000 |
| 3 | Willful Neglect (Corrected) | $10,000 - $50,000 |
| 4 | Willful Neglect (Not Corrected) | $50,000+ |

**Annual Maximum**: $1.5 million per violation category
